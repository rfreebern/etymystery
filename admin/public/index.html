Keyboard shortcuts

Enter
save the current word and move to the next
← →
previous / next word (an entered year is saved on the way)
1…9
scroll to that source (the numbers are in each source header)
r
reload the first source frame
z
cycle iframe zoom (60 → 70 → 80 → 90 → 100%)
s
skip this word (adds it to the skip list)
m
merge the batch into curated/curation.json
?
show or hide this panel

Typing in the year or blurb field never triggers these — only the shortcuts above, and only when you are not in a text field.
